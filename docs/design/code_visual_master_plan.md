## Objective and scope

Build an extensible system that imports source projects into editable, text-shaped graphs and regenerates ordinary source with documented fidelity. Cover all eight current programming-language targets: JavaScript, Python, C#, Go, GDScript, Rust, C++ and Verse. JSON is a data/output format and needs its own schema/data mapping; it is not an executable-language adapter. Future languages, dialects and version updates enter through the same adapter and evidence contract.

“All scripts” is the long-term coverage objective. Delivery claims apply to declared language versions, syntax features and project contexts. Dynamic dispatch, reflection, generated source, conditional compilation and unavailable external dependencies require explicit modeling or unresolved diagnostics; static import cannot invent runtime facts. Unsupported source remains available verbatim in the review. It never silently disappears, becomes hidden editable source, or counts as a successful visual conversion.

Verse/UE6 reverse-import work is now authorized. Authoritative grammar, native validation access and supported host profiles remain prerequisites; authorization does not establish those capabilities. No in-app interpreter, Run button, VM or mandatory VVS runtime is introduced.
