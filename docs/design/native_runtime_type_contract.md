# Unknown-parameter scalar operator typing

`packages/graph-types/src/nativeRuntimeTypes.ts` supplies pure operator applicability and result-type facts for the pinned C++17 Windows/MSVC LLP64, Rust edition2021 and Godot4.5.2 scalar profiles. Inputs are canonical native parameter/operand types. Returned facts are immutable, retain `values: unknown`, and distinguish ordinary from short-circuit evaluation. This API does not manufacture parameter values or route runtime operations through constant evaluation.

C++ integer promotions and usual arithmetic conversions preserve native rank, signedness and the LLP64 distinction between `long` and `long long`. Shifts use promoted left-operand type. Rust arithmetic requires matching operand types; shifts may use a different integer right operand. Rust Boolean bitwise operators and ordering retain Boolean results, unsigned negation and unary plus reject, and numeric-to-Boolean casts reject. Godot integer/Boolean operators remain native-specific: Boolean ordering is accepted, while Boolean addition and Boolean XOR reject. Godot integer logical operands produce Boolean short-circuit results.

The Boolean-order observation came from a compiler contrast that contradicted the initial policy. It is now a native-backed case rather than an assumption copied from another language. Native negative fixtures discard the operator result without a destination constraint, so a return mismatch cannot hide operator applicability.
