# C# visible integral graph contract

IR v12 adds native C# integral expression forms on existing visible literal/operator nodes. Exact literal tokens, unary/binary operators, explicit casts, authored parentheses and checked/unchecked expression contexts remain graph-owned and are emitted through C# syntax packs. Inferred exact facts are transient; printing never folds authored expressions or converts tokens through JavaScript Number.

Graph validation resolves parameter identities from the visible native entry and the matching Function Define signature. It recursively applies the pinned-Roslyn-backed C# integer policy, checks contextual return assignment and rejects cycles, excess depth, orphan expressions, malformed operands and hidden inline substitutions. Operator/cast contexts nest structurally; a checked outer expression does not erase an inner unchecked expression. Direct minimum-value negation is distinguished from negation of a parenthesized unsigned literal.

The developer fixture set contains 25 composed graph expressions: all supported binary operators, masked/unsigned shifts, minimum-value lexical contexts, exact UInt64 spelling, checked/unchecked casts and arithmetic, byte promotion, char conversion/complement and runtime parameter expressions. Native validation compares generated expression types/constants to graph facts and also compiles each original generated class separately. Compilation does not prove runtime success; fixture programs are never executed. Source maps, function-tab output, JSON reload and invalid graph mutations are checked through the canonical transpiler path.

The fixed csharp-expression.fixture.json exercises an unchecked byte cast. Shared production/Pages browser checks exercise its actual Code panel, checked-overflow invalid edit/recovery and persistence. The signature workflow separately covers invalid narrowing, widening, exact native types, save/reload and function-tab output. Observed validation: 590 native cases (425 accepted/165 rejected), 25 graph/native pairs, 2,573 package and 1,153 web tests, native/type/lint/build and production/Pages browser workflows pass. Unchanged Go/host/server/golden gates retain preceding evidence; see current_state.

This is not C# source acceptance or full C# completion. Source planning/materialization, local/constant declarations and scopes, ordered expression calls/overloads, statement overflow contexts, Boolean comparisons, floating/decimal/native-sized domains, nullable/reference/string/char-literal policies, types/members, advanced flow/effects, projects/references and conflict-aware reimport remain required. Dedicated inspector coverage of all operator/cast edits remains required beyond the currently exercised overflow/signature workflows.
