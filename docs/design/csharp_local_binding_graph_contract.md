## Implemented policy

`csharpIntegralLocal` in graph-types owns predefined integral initialization for both source binding analysis and graph local inference. Explicit types use native implicit assignment rules; `var` retains the initializer's native type. A const binding must have an explicit supported type and native constant initializer. Its read fact retains the converted constant and declared width. Mutable reads retain their declared type and discard constant facts even when initialized from a literal. Inferred values are transient; exact authored expression nodes remain the source of output.

The existing 494 source-binding/native pairs exercise this shared policy through the C# binder, independently comparing Roslyn expression/converted/declared types, constant availability and call signatures. Native evidence now adds four independently compiled generated local graphs and four native local-read fact probes, plus original/regenerated source review, acceptance and reimport pairs, totaling 670 cases (505 compiler-valid/165 rejected). This covers selected source policy and emitted straight-line graphs, not complete C# scope semantics or every local inspector operation.

## Visible graph contract under construction

`inferCSharpLinearLocals` recursively walks lexical execution regions from a native C# Function Entry through initialized Variable Define nodes to a return or, for a void result, a natural end. The latter emits no return node or statement; value-returning signatures still require an explicit return. It derives facts from each visible initializer before adding the binding, preventing self/forward reads. Parameters and earlier locals reserve normalized case-sensitive/verbatim identity. Duplicate/shadowing bindings, malformed execution paths, cycles, mismatched readonly settings, unsupported types and hidden/ambiguous initializer inputs are rejected.

| Declaration spelling | Visible local style | Native type property | Read fact |
|---|---|---|---|
| `byte First = value;` | `csharp-typed` | `byte` | Declared type, no constant |
| `var Second = value;` | `csharp-var` | `var` | Inferred native type, no constant |
| `const byte Limit = value;` | `csharp-const` | `byte` | Converted declared type and exact constant |

Variable Get resolves a preceding local's visible symbol identity and defining node, with one Number output and no hidden inputs/inline values. Its emitted name metadata must match the binding's declaration name; otherwise symbol-based inference could validate a different identifier from the one lowering prints. A combined index/declaration rename with stale getter metadata is a blocking regression case. Graph expression inference forwards the same transient environment through operators/casts/overflow wrappers. No cached source constant or generic Number pin can supply native identity.

Mutation tests use the already-native-verified unchecked byte-cast expression as a visible initializer, then chain const and mutable local reads. They cover recomputation after literal edits, normalized JSON persistence, self/forward references, shadowing, readonly/type changes, hidden input/incorrect pin edits, ambiguous initializers, cycles and checked-overflow failure. IR v13 now prints explicit typed, inferred and const declarations through C# pack templates; graph body analysis checks one execution chain, index/pin/readonly ownership, native return conversion and orphan values. Four composed native graph/compiler pairs cover const byte pipelines, exact signed minimum constants and runtime byte/char promotions. The fixed csharp-local.fixture.json also survives full project normalization and class/function-tab Code-panel output. Source local planning, structural comparison and sealed acceptance/reimport are implemented. The source planner preserves declaration order and typed/var/const spelling, resolves only preceding bindings and retains supported initialized groups through visible shared declaration owners instead of flattening them. Production and Pages now verify actual source import, nine native type choices, invalid widening/recovery, save/reload and atomic invalid forward-group rejection. Typed/var/const style conversion now preserves inferred width, readonly index, initializer pins and selection through one lifecycle transaction; production and Pages verify cycling/reload. Other inspector variants remain open.
