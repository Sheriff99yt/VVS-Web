# Ordinary native scalar function headers

Rust/C++/GDScript source analysis now retains frozen ordinary top-level function signatures: exact name/parameter/type/return/body spans, authored spelling, canonical native scalar identities, parameter mutability and authored modifiers. Source/hash inventory retains every unresolved region. Nested closures and unsupported enclosing template/class/impl constructs do not become ordinary standalone headers.

The pure graph-types signature contract supplies Boolean/integer type identities and pin domains without a source-import dependency. C++ authored aliases retain their spelling while canonicalizing signed/unsigned short/int/long/long-long identities under the existing Clang LLP64 profile. Rust supports Boolean and explicit integer widths, including pointer-sized integers under the pinned pointer64 profile. Godot supports Boolean/int. Rust omitted returns become native unit; C++/Godot void is explicit. This is header analysis, not type inference for arbitrary bodies.

Pointers/references, generics, defaults/variadics, floating/string/aggregate/native host types and untyped Godot headers remain unresolved prerequisites. Native-valid unsupported headers are explicitly tested. Source modifiers and parameter qualifiers are retained, not silently injected into emitted functions. Header facts do not validate body effects, calls, symbol ownership, assignment/return conversion or native project contexts.

Curated compile-only fixtures provide C++/Rust typed function-pointer assignments and Godot isolated check-only acceptance. Exact source hashes and name/type spans are checked by `native-signatures`. C++ uses standard type aliases and typed assignments: the pinned browser grammar did not parse Clang's __is_same function-pointer type arguments even though Clang accepted them; native extension syntax remains a grammar/source-retention roadmap gap. The generic harness report label describes its scalar origin; this consumer/contract defines the narrower header scope. No fixture source programs execute. The stage is explicit and excluded from default validation pending portable tool provisioning. `--retry-native-signatures=<language>/<case-id>,...` recompiles selected changed cases while the shared harness requires matching source/expectation/actual-file/command/toolchain evidence for retained cases.

Run `packages,source-import-types,native-signatures` as one affected batch. Retain matching earlier literal/constant/source/graph/native and unchanged app evidence. Graph admission stays blocked until authored headers are wired through actual registry/inspector/IR/packs, independently validated bodies, canonical Code-panel/native compiler proof and browser import/edit/save/reimport acceptance. This contract does not certify full language adapters.
