# Native runtime source admission and lifecycle

This packet extends the established C++17 Windows/MSVC LLP64, Rust edition2021/rustc1.99 Windows/MSVC library and Godot4.5.2 ordinary Library subsets with parameter-dependent integer/Boolean expressions. It covers nested arithmetic, comparisons, logical conditions, authored grouping and explicit reviewed conversions. Source/header/parameter ownership and native result types must match the visible saved function graph. Unknown parameter values remain unknown; compiler acceptance does not prove runtime values, overflow safety or effects.

## Atomic admission

The source worker's preview and sealed review enable runtime expression materialization. The public analysis preview retains its explicit `runtimeExpressions` option. Worker preview exposes a candidate without an acceptance receipt; review rebuilds and validates the complete project, canonical generated syntax and save/reload state. Acceptance consumes the existing private review seal/current-generation single-use worker receipt. Copied, stale or mutated reviews remain rejected. Unsupported statements or declarations retain source and diagnostics without admitting a partial module.

Accepted modules contain actual registry-versioned definition, entry, literal, operator/group/conversion and Return nodes with explicit operand/parameter wiring and source origins. Original source remains provenance; Code-panel generation reads the graph. Native signature transactions coordinate symbols, definitions and body ports; incompatible return or parameter edits block generation rather than introducing conversions.

## Editor and reimport evidence

The composed fixtures are three modules containing nine functions: arithmetic, a nested Boolean condition and an explicit Boolean-to-integer conversion in each language. The actual browser workflow imports each module through worker review/acceptance, changes and restores the authored return type, makes an invalid literal edit and recovers, changes literal `2` to `3` and multiplication to addition, saves/reloads, retains graph edits on unchanged-source reimport and resolves changed-source conflicts through both keep-graph and use-source choices. Incoming source changes multiplication's literal to `4`; save/reload retains the new provenance and output.

Floating panel close controls have an accessible name. Browser navigation closes the literal inspector before selecting a node covered by that panel; clicks are not forced through an overlay.
