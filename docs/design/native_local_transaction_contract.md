# Native scalar local inspector transactions

This packet follows [local graph/Code-panel ownership](native_local_graph_code_panel_contract.md) for ordinary Library functions in the pinned C++17/Clang19.1.5 LLP64, Rust2021/rustc1.99 and Godot4.5.2 profiles. It implements coordinated inspector edits; local worker and live browser acceptance are separate required dependencies.

## Pure edit boundary

`graph-types/nativeScalarLocalTransactions.ts` exports `NativeScalarLocalEdit`, `nativeScalarLocalEditorProfile` and `transactNativeScalarLocal`. The edit contains only name, authored scalar type and mutability. The visible declaration establishes native type, owner and symbol identity. Actual function definition/entry/overload/body ownership and the matching variable index must agree; duplicate declarations/indexes and foreign read/write ownership reject before mutation. A full body-validity precondition is deliberately absent: a user must be able to recover after a supported edit creates an invalid assigned type or readonly write.

Transactions clone documents, retain stable declaration/symbol/edge identities and source provenance, and update the exact declaration plus its bound reads/writes. Read/write names follow the declaration and their value ports follow its explicit native type. The index retains graph/class identity and mirrors name, pin domain and readonly status. Only changed source output types refresh outgoing edge metadata. No edge is erased, conversion inserted, expression recalculated or unrelated diagnostic repaired. Native scalar pin typing now exposes its actual Boolean/number union to variable and graph consumers.

## Inspector integration

`useSymbolLifecycle.updateNativeScalarLocal` records history, updates variables and patches documents while preserving the current view and node selection. `NativeLocalPanel` exposes authored type options, explicit mutability and a name field committed on blur/Enter in a collapsed section. Both native declaration-node details and selected native variable-index details use this panel. Generic default/binding/initializer/style controls are excluded from that native declaration inspector so an index-only edit cannot imply an emitted declaration change. Name drafts reset by binding/name identity without a synchronous effect.

Readonly and type edits may leave incompatible operand connections intact. Canonical project analysis/Code-panel generation blocks those graphs; reverting the explicit edit restores valid output without reconstructed wires or guessed values. Unsupported native contexts remain blocking.
