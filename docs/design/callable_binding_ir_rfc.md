# MP-03 through MP-07 structural contracts

The approved remaining master-plan batches are delivered in dependency order. No source snippet or opaque parser tree may replace visible callable, binding, control, type, project or trivia nodes. New language adapters need independent pinned grammar and native evidence before acceptance.

The first IR amendment adds native parameter records to FunctionDecl: stable parameter ID/name, positional/rest/keyword modes and optional graph-owned default expression. Define owns the signature and exposes default expression pins. Symbol parameters remain indexes. Calls retain exactly the supplied ordered argument pins; omitted defaults and variadic arguments never become hidden generated literals. Native call bindings are validated against the visible signature and target. Header spans include every default expression. This preserves JS call-time and Python definition-time evaluation by printing the actual native default syntax.

Python function-wide locals may be initialized by assignments on different paths. Definite-assignment analysis intersects the initialized sets of surviving branches and records initialization from either Declare or Set; a missing path still blocks reads. JS lexical rules remain distinct.

Follow-on callable values/captures, binding patterns, cleanup/suspension, type/member initialization, project closure and trivia amendments must retain their native scope/effect ownership, source maps, target gates, persistence and Code-panel evidence. The active all-complete goal includes UE6/Verse; earlier deferral has been superseded.


## IR v12: native C# integral expressions (October 6, 2026)

Native parameter types now include the reviewed C# fixed-integral domain. Function Define owns these static-class method signatures; explicit native entry markers resolve case-sensitive/escaped parameter reads. IrNativeExpression retains exact C# scalar tokens, predefined unary/binary operators, explicit integral conversions, authored parentheses and checked/unchecked expression context. Parentheses and overflow forms are visible operator nodes with one operand; contexts nest structurally. Emitters use C# syntax-pack templates and do not serialize/fold inferred constants. Direct negated minimum literals remain adjacent to their token, while authored parentheses around that token remain visible and preserve the different native type.

Transient saved-graph inference uses the Roslyn-backed C# integer policy and rejects malformed/cyclic/orphan operands, hidden inline substitutions and invalid return conversions. Numeric pin geometry alone does not establish native type or validity. This amendment does not enable C# source acceptance, locals, calls or wider value/effect/project domains; those remain required implementation work.
