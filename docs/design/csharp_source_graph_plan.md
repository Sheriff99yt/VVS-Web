# C# source-to-graph planning foundation

Nested/checked scope integration follows [the lexical scope contract](csharp_lexical_scope_contract.md). Source analysis exposes immutable scope ownership and binding-reference occurrences; visible scope nodes, recursive environments, structured IR v15, scope-context inspector editing, persistence and reimport are verified for the composed integral block subset. Initialized typed/const groups now have visible shared owners/declarators, IR16 and atomic inspector/persistence/reimport proof; see csharp_declaration_group_contract.md. Uninitialized/definite assignment, membership/split-merge/trivia and unreachable regions remain required.

The UI-free `planCSharpIntegralClass` parses source into typed ClassImportPlan records and uses the shared transactional materializer. `reviewCSharpImportGraph` rebuilds that whole plan, validates its graph and issues a sealed acceptance receipt. The worker/dialog now expose this bounded subset through reviewed browser acceptance and reimport.

Mapped units are ordinary classes with explicit public or omitted visibility, containing public static fixed-integral/void methods. Parameter names preserve case and verbatim spelling; reads resolve normalized identifier identity to stable plan parameter IDs. Methods support expression bodies or initialized typed/var/const locals in straight-line and nested ordinary/checked/unchecked blocks, plain/compound assignments and standalone prefix/postfix updates to locals and by-value parameters and final explicit return or natural void completion. Return expressions retain exact numeric tokens, predefined operators, casts, parentheses and nested overflow contexts. Define nodes own native signatures; body entry markers own parameter reads. All nodes retain source spans/hash for provenance, and graph generation still works after provenance is removed.

Namespaces, attributes, generic/partial/static class modifiers, fields, overload graph ownership, uninitialized locals/definite assignment, calls/advanced statements, non-integral domains and trivia beyond the current contract are rejected as whole plans rather than dropped. The analysis inventory continues retaining unsupported source. These are required follow-on mappings, not a reduced completion target.

The native validator performs 25 source → typed plan → materialized graph → sealed review/acceptance → reimport → regenerated C# comparisons against Roslyn types/constants, and compiles each actual regenerated class separately. Inputs are composed from the existing 25 expression fixtures with generated declaration comments removed; this is bounded fixture evidence, not broad project conformance. The shared five-method browser fixture is independently compiled in both original and regenerated form. The native corpus totals 642 cases: 477 compiler-valid and 165 rejected. The fixed native-csharp-class.fixture.json adds several methods, case-sensitive parameters, checked arithmetic, unchecked conversion, minimum-value negation and a void return.

Reload revealed that normalizeClassSymbols inserted public for omitted class visibility and discarded protected visibility. It now preserves supported visibility values and omission. Materialized C# class nodes store an explicit empty visibility value to preserve source spelling; class indexes retain undefined for omitted visibility. Snapshot normalization, JSON reload, generated source maps and provenance removal are tested. Final batch results are recorded in current_state.

Current expansion adds seven composed local assignment sources and five by-value parameter-write sources, a fixed saved mutation graph and the native mutation cross-product; see [current evidence](../current_state.md). Counts in the original foundation paragraphs above are historical.

## Core review and reimport contract

`normalizedCSharpSyntax` compares one ordinary class, method/parameter signatures, exact numeric tokens, operator trees, casts and nested overflow contexts. It accepts expression-body/block-return formatting and redundant printing parentheses while preserving unary-minus/minimum-literal adjacency, including hexadecimal and underscore spellings. Unsupported syntax is rejected rather than omitted. Native graph analysis and source binding checks remain independent gates; structural equality is not a full native compiler claim.

Acceptance rejects changed source/hash, path, entry options, graph and forged review copies; it returns a fresh copy of the sealed snapshot. C# class imports require Library mode and a flat .cs path. Save/load, source provenance and generated ownership pass the shared import validator. Unsupported whole-file additions still cannot obtain receipts.

Three-way reimport rebuilds both original and incoming source through the C# review gate and retains project settings, output paths, graph metadata and persistence. Graph-only changes remain by default; conflicting source and graph edits require a reviewed choice. Settings/current-graph/review changes invalidate the transaction. Reimport comparison includes generated comments so authored graph explanations are retained. Additional authored units, unsupported incoming source and invalid current graphs block replacement atomically.

## Browser admission and verified lifecycle

The worker returns the immutable source inventory plus a separate eligibility region after whole-class planning; this never carries a snapshot or receipt. Review replans the source with the real .cs path and entry options before sealing. Acceptance uses the worker-owned review identity and rejects changed source/path/graph/target. Preview/review replacement retires receipts, and superseded async review/acceptance cannot publish results. The client retains hard cancellation/deadline behavior. Unsupported source is retained with declarations, binding observations and mapping diagnostics.

Production and Pages verification import the shared five-method fixture via .cs upload, review/accept it as a new project, edit a native signature into an invalid narrowing and repair it, widen its result, save/reload and compare the function-tab Code panel. Unchanged source preserves graph-only changes; simultaneous source changes exercise both keep-graph and use-source choices, source replacement survives reload, and an additional unsupported class blocks replacement. Existing C# cold-load/source-analysis/signature/overflow workflows and all 48 other-language production imports remain regression gates. Browser checks explicitly frame the virtualized graph before selecting its signature owner and use canonical binding identity instead of a kind spelling.

Next integrate local/constant scopes, ordered calls and overloads with the remaining native type/effect/project contracts. Namespace/reference closure and full compiler/context validation remain open. Full C# and eight-language coverage are not claimed.
